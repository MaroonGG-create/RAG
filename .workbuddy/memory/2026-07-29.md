- 消息落库时机：用户消息先存（流式开始前）；助手消息在 token 全部收集后一次性 INSERT（不在流式中逐 token 写 DB）

- Mock 流式：按 5 字符分块、每块延迟 50ms 输出，确定性可验收
- MessageReference 快照设计：documentId/chunkId 无 FK，文档删除后引用保留
