## T06 文本清洗与切片任务设计

- 完成了 `docs/task-06-text-cleaning-and-chunking.md` 的设计与编写（748 行，21 章节）
- 核心设计：接收 T05 的 ParsedDocument → 逐页 cleanText → 递归字符切分 → DocumentChunk 批量落库
- 清洗规则：换行归一化 + 删零宽字符 + 压缩连续空行 + trim；不清洗 Markdown 标记/标点/URL
- 切片算法：递归按 SEPARATORS=['\n\n','\n','。','！','？','. ','! ','? ',' ',''] 分割 + 合并重叠；不跨页

- 状态机：pending → chunking → (成功留 chunking / 失败 failed + chunkCount=0)
- 幂等：status=chunking AND chunkCount>0 短路；重跑时事务内 delete 旧 + insert 新
- 失败补偿：catch 中 delete chunks 兜底 + 置 failed + chunkCount=0
- 配置：新增 CHUNK_SIZE(默认500)/CHUNK_OVERLAP(默认100) 环境变量

## T07 Embedding 服务任务设计

- 完成了 `docs/task-07-embedding-service.md` 的设计与编写（1064 行，20 章节）
- 核心选型：Node.js 20 内置 fetch + AbortController 手写 HTTP 客户端，零新增依赖
- 否决 openai SDK（传递依赖冗余）、axios（Node 20 已有原生 fetch）
- 新建独立 EmbeddingModule（src/modules/embedding/），不侵入 processing 模块
- EmbeddingClient：纯 HTTP 客户端（仅依赖 ConfigService），含 Mock 分支 + 指数退避重试
- EmbeddingService：编排服务（读 DocumentChunk → 分批 → 状态流转 → in-flight 去重）
- 批处理：按 chunkIndex 升序分批串行调用 API，不并行（防限流）
- 重试策略：指数退避（base=1000ms, factor=2, max=30s, jitter）；429/5xx/超时重试，4xx 不重试
- 三重校验：向量数量/顺序/维度
- Mock 模式：EMBEDDING_MOCK=true，SHA-256 确定性伪向量 + L2 归一化
- 状态机：chunking → embedding → (成功留 embedding / 失败 failed)；completed 防御性拒绝
- 向量不持久化：embedDocument() 返回 EmbeddingResult 内存对象交给 T08
- 环境变量：EMBEDDING_BASE_URL/API_KEY/MODEL/DIMENSION/BATCH_SIZE/TIMEOUT_MS/MAX_RETRIES/MOCK
- CLI：pnpm --filter server embed:document <id>
- 与 T08 接口：T08 调 embedDocument() 获取向量 → 写 Qdrant → 置 completed

## T08 Qdrant 向量存储任务设计

- 完成了 `docs/task-08-qdrant-vector-store.md` 的设计与编写（1152 行，21 章节）
- 核心选型：`@qdrant/js-client-rest@1.12.0`（官方客户端，CJS 入口兼容 Node 20，与 Qdrant Server v1.12.4 对齐）

- QdrantClientWrapper：封装 @qdrant/js-client-rest + Mock 分支（内存 Map 模拟）
- VectorStoreService：OnModuleInit ensureCollection + storeDocument 编排 + deleteByFilter
- Collection 自举：不存在则创建（size=EMBEDDING_DIMENSION, distance=Cosine）+ 建索引（knowledgeBaseId/documentId）；已存在则校验维度/距离，不匹配 fail-fast

- 状态机：embedding → completed（成功）/ failed（失败+清理半成品向量）；completed 防御性拒绝
- 幂等：每次先 deleteByDocumentId 再 upsert；upsert wait:true
- 失败补偿：catch 中 deleteByDocumentId 清理半成品 + 置 failed

- Mock 模式：QDRANT_MOCK=true，内存 Map 模拟 Qdrant 全部操作
- 环境变量：QDRANT_COLLECTION(rag_chunks)/QDRANT_UPSERT_BATCH_SIZE(100)/QDRANT_MOCK(false)
- CLI：pnpm --filter server store:document <id>
- 与 T09 接口：completed 文档可被向量检索；T09 用 Qdrant search + filter knowledgeBaseId
